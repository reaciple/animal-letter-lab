# v1.10.0 · 코인길 모험과 장비 상점

첫 화면은 상단 메뉴만 사용합니다. 코인 달리기 → 아이 도감 → 친구 사진 → 모험 캠프에서 달리기와 장비 상점을 이용하세요.
같은 약 1분 코스에 나무토막, 바위, 버섯, 수레, 구덩이와 순한 몬스터 2마리를 포함해 16곳을 배치했습니다. 점프 안내, 2단 점프, 에너지 자동 회복은 그대로입니다.
길에 있는 아이템을 지나며 주운 다음, 화면 아래 버튼을 눌러 원하는 순간에 사용하세요. 비눗방울은 6초 보호, 코인 자석은 6초 동안 먼 코인 수집, 별빛 종은 앞의 장애물 또는 몬스터 하나를 없앱니다. 달리기 아이템은 이번 판에서만 사용할 수 있습니다.
완주 때 10원 × 코인 수가 자동 적립됩니다. 중간에 캠프로 나가면 적립되지 않습니다. 다른 아이나 다른 캐릭터의 지갑과 섞이지 않으며, 같은 합체캐릭터의 첫 그림·먹이 후 그림은 같은 지갑을 사용합니다. 연습 친구 지갑은 별도입니다. 예전 버전의 한 판 금액은 저장되지 않았으므로 소급할 수 없습니다.
상점에서 무기(별빛 지팡이 80원, 무지개 검 150원)와 방어구(도토리 방패 60원, 달빛 투구 120원)를 구매한 뒤 장착을 누르세요. 슬롯별로 하나씩 바꿔 끼우거나 해제할 수 있습니다. 캠프·달리기 아바타에 장비 아이콘이 표시됩니다. 원본 사진은 변경하지 않으며 이번 버전의 장비에는 전투 능력치가 없습니다.
지갑과 장비는 현재 기기의 같은 브라우저에 저장됩니다. 부모 설정 백업에 함께 포함됩니다. 복원은 병합 방식이며 같은 캐릭터 지갑이 이미 있으면 현재 지갑을 유지합니다. 구버전 도감 백업도 복원할 수 있습니다.

## 적용 순서
1. 지금 사용하는 브라우저의 부모 설정에서 백업을 한 번 내려받으세요. 사이트 데이터는 지우지 마세요.
2. GitHub reaciple/animal-letter-lab 저장소의 기존 배포 위치에 ZIP의 github-pages 폴더 **안에 있는 내용 전체**를 올리고 Commit changes를 누릅니다. source와 worker는 GitHub Pages에 올리지 않습니다.
3. Cloudflare에서 기존 Worker의 코드 편집기를 열어 worker/cloudflare-worker.js 전체로 교체하고 Deploy를 누릅니다. 서버 코드 정리를 적용하는 단계입니다. 새 키·변수·D1 스키마 변경은 없습니다.
4. Pages 배포 후 원래 게임 주소에서 새로고침하고 v1.10.0, 도감, 코인 달리기 메뉴를 확인합니다.
5. GitHub 업로드만으로 옛 파일이 삭제되지는 않습니다. 새 버전 확인 후 아래 항목만 정리하세요.

## GitHub에서 파일을 삭제하는 방법 (PC)
게임 화면이 아니라 로그인한 GitHub 저장소의 Code 탭에서 파일 이름을 눌러 여세요. 파일 화면 오른쪽 위의 점 세 개(…) 메뉴 → Delete file → Commit changes. 폴더는 폴더를 연 뒤 같은 메뉴의 Delete directory로 삭제할 수 있습니다. 보호 브랜치라면 새 브랜치로 커밋 후 Pull request로 반영하세요.
- 삭제 후보: 이전에 제공한 animals 폴더의 bear.png, bull.png, elephant.png, fox.png, giraffe.png, lion.png, panda.png, rabbit.png, tiger.png, turtle.png 및 옛 animal-photo-prompts.txt. 직접 추가한 파일이 섞여 있다면 폴더째 삭제하지 말고 해당 파일만 삭제하세요.
- 이전 v1.9.0 자산 index-Bvm08pur.css와 index-BWs1nEvM.js는 v1.10.0 배포 확인 후 삭제할 수 있습니다. assets 폴더 전체나 새 index.html이 참조하는 JS/CSS는 삭제하지 마세요.
- mascot.png와 favicon.svg는 현재도 필요합니다. 태블릿에 부모님이 등록한 사진과 도감은 이번 GitHub 파일 정리 대상이 아닙니다.
