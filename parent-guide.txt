캐릭터연구소 1.11.0 · 그림책에서 운동장까지

설치
1. 기존 게임 부모님 → 도감 전체 백업으로 현재 상태를 보관합니다.
2. GitHub의 기존 Pages 배포 위치에 github-pages 폴더 안의 파일과 assets 폴더를 올리고 Commit changes 합니다. 폴더 이름 github-pages 자체를 추가하지 마세요.
3. 기존 Cloudflare Worker의 코드를 worker/cloudflare-worker.js 내용으로 교체하고 Deploy 합니다. 긴 코드가 잘 안 붙으면 worker/paste-parts 안의 01.txt부터 숫자 순으로 한 편집창에 이어 붙인 뒤 마지막에만 Deploy 합니다. API 키, 한도, D1과 기존 사이트 주소는 그대로 사용합니다.
4. 평소 게임 주소에서 새로고침하고 동물 경주 메뉴를 확인하세요. 사이트 데이터 삭제는 필요하지 않습니다.

놀이
- 아이 카드의 ‘진행 초기화 · 새로 시작’은 해당 아이의 이번 놀이와 연습 글씨만 비웁니다. ‘만들기 · 이어 하기’는 잠시 멈춘 놀이에 돌아갑니다. 이름 저장으로 완료한 다음 놀이는 빈 글씨로 시작합니다.
- 캐릭터 두 명 고르고 쓰기 → 첫 그림 → 먹이 주기 또는 건너뛰기 → 이름과 그림책. 기존 도감의 그림은 그대로입니다.
- 4·6·8장의 삽화가 모두 저장된 그림책은 첫 장부터 ‘그림책 장면 순서 맞추기’가 보입니다. 예전 완성본도 도감에서 열 수 있습니다. 원고만 있고 삽화가 빠진 경우 ‘남은 그림 이어 만들기’를 먼저 이용하세요.
- 손가락이나 S펜으로 옮기거나 그림과 숫자를 차례로 누르세요. 맞으면 고정되고 틀리면 제자리로 돌아옵니다. 매 판 완성하면 아이의 신발 지갑에 5~10원이 한 번 지급됩니다. 다시 열고 풀면 또 벌 수 있습니다.
- 동물 경주: 도감의 친구 선택 → 상대 선택 → 신발 가게 → 경주. 아이별 신발 지갑과 신발 소유 목록은 공유하고, 어느 신발을 신었는지는 캐릭터별로 보관합니다. 기존 코인 달리기와 장비 상점의 돈은 별도입니다.
- 맨발은 4. 5~10원 운동화의 보너스는 +2~+7. 상대 숫자는 실제 야생동물 속도가 아닌 게임 레벨(5~10)입니다. 같은 박자로 톡톡 누르면 레벨이 높은 쪽이 앞섭니다. 느리게 누르거나 쉬면 더 낮은 레벨의 상대도 먼저 도착할 수 있습니다.
- 태블릿은 화면 발판, PC는 Space/Enter를 사용합니다. 한쪽만 눌러도 됩니다. 기존 사진도 종이 인형처럼 다리 부분을 나누어 움직이고 새 합체 그림은 발이 잘 보이도록 요청합니다. 상대 10종은 자체 그림으로 움직이므로 이미지 추가나 유료 생성이 필요 없습니다.
- 기존 백업 v1~7도 읽습니다. 새 전체 백업 v8에는 신발 지갑이 포함됩니다. 복원할 때 같은 아이의 신발 지갑이 이미 있으면 현재 지갑을 유지합니다.
