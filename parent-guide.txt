경주 상대는 한 마리에서 세 마리까지 고를 수 있어요. 다시 누르면 선택을 해제해요. 경주는 항상 입체 경기장에서 열려요. 선수 소개는 건너뛸 수 있어요.

업데이트: 평소 쓰는 브라우저에서 부모님 → 게임 전체 백업 · 복원으로 먼저 백업하세요. 업데이트 ZIP의 github-pages 폴더 안 파일·폴더를 기존 저장소의 index.html과 같은 위치에 올려 함께 커밋하세요. 같은 게임 주소를 새로고침해 v1.27.0을 확인하세요. v1.19에서 Cloudflare Worker 변경은 없습니다.

순서 맞추기 한 판에 5원. 기본 속력 5, 새싹·물결은 3원/+3, 구름·혜성은 4원/+4, 번개·무지개는 5원/+5. 상대 속력은 7~10입니다. 코인 초기화 시 그 아이의 잔액과 모든 선수가 소유한 날개가 함께 초기화됩니다.
새싹 날개로 초당 한 번 누르면 약 33초입니다. 같은 속력에서는 빠르게 눌러도 근소한 차로 이기도록 조정했습니다.
합체 후 바로 이름과 그림책으로 진행합니다. 이전 먹이 사진은 도감에 남습니다. 먹이는 동물 경주 대기실에서 사과 1원, 바나나 2원으로 구입하고 별도 먹이기 버튼을 누르세요. 잔액과 먹이 수량은 아이별로 저장되고 먹이 반응은 추가 API 비용 없이 바로 나옵니다.

부모님 → 날개와 꼬리 효과 꾸미기: 원하는 날개를 선택하고 날개 한 짝 또는 꼬리 효과를 펼쳐 요청문을 복사하세요. 생성 앱에서 투명 또는 단색 자홍 배경의 PNG 한 장을 만들어 해당 항목에 등록하세요. 한 번에 열두 장을 준비할 필요는 없습니다. 한 짝을 게임이 좌우로 맞추고 팔랑이게 합니다. 꼬리 효과는 한 장을 반복해 작아지며 사라지게 표시합니다. 각 항목만 기본 그림으로 되돌릴 수 있습니다. 이미지와 효과는 전체 백업에 포함됩니다.

## 다른 기기에서 이어 하기
- 쓰던 기기: 부모님 → **게임 전체 백업 · 복원** → **전체 백업 받기** → 새 암호를 두 번 입력 → **암호화 파일 다운로드**. .forest 파일과 암호를 각각 보관하세요. 별도 앱이나 계정이 필요하지 않습니다.
- 새 기기: 같은 게임 주소(v1.20 이상) → 부모님 → **게임 전체 백업 · 복원** → **새 기기에 복원** → .forest 파일과 암호 → **백업 확인하고 복원**. 작품 수를 확인하고 교체에 동의하면 게임이 다시 열립니다.
- 도감, 등록 사진·경주 선수 시트, 그림책과 질문, 부모 설정·저장한 프롬프트, 지갑·날개·장비, 기기에 저장한 연습 및 진행 기록, Worker 주소·가족 연결 코드가 포함됩니다. 생성 요청을 다시 보내지 않습니다. OpenAI API 키·서버 사용량은 Cloudflare에 그대로 있습니다. 새 기기에서도 같은 서버를 씁니다.
- 이 방식은 **백업한 시점으로 이 브라우저의 게임 전체를 교체**합니다. 두 기기를 실시간으로 동기화하지 않습니다. 암호를 잊으면 복원할 수 없습니다. 기존 도감 JSON은 **도감 백업과 합치기**에서 계속 사용할 수 있습니다.

보리의 가게: 날개를 미리 보거나 먹이를 고른 다음 지갑의 동전을 하나씩 눌러 주세요. 계산대 동전을 누르면 돌려받고, 가격과 같을 때 계산하기를 누르면 구입합니다. 취소하면 잔액은 그대로입니다.
둘이서 이어달리기: 상대 동물 1~3마리는 각자 두 바퀴를 계속 달립니다. 두 아이는 한 바퀴씩 달리고 바통 화면에서 잠시 경기 시계를 멈춥니다. 두 번째 주자는 상대와의 거리 차이를 그대로 이어받습니다. 시상식에서 두 선수는 한 단상에서 같은 메달을 받습니다.
