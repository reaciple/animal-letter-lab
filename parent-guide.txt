# 캐릭터연구소 v1.7.0 · 도감으로 다시 놀아요

이미 v1.6.0의 그림책 생성이 정상 작동한다면 **이번에는 GitHub Pages만 업데이트하면 됩니다. Cloudflare 수정은 필요 없습니다.** 새 키·계정·DB를 만들 필요가 없습니다. 제공 파일은 누적 완성본이며, 사이트에 직접 배포한 상태는 아닙니다.

## 업데이트하는 순서

1. 지금 사용하던 게임의 **부모님 → 도감 전체 백업**을 눌러 백업 파일을 보관합니다.
2. `animal-letter-lab-update-v1.7.0.zip`을 다운로드하여 압축을 풉니다.
3. GitHub에서 `reaciple/animal-letter-lab` 저장소를 엽니다. 기존 `index.html`과 `assets`가 있는 배포 위치로 이동합니다. 일반적으로 저장소의 첫 화면입니다.
4. **Add file → Upload files**를 누릅니다.
5. 압축을 푼 폴더에서 **github-pages 폴더 안에 들어 있는 파일과 폴더 전부**를 올립니다. `index.html`, `assets` 폴더, 사진·안내 파일 등을 함께 올립니다. `github-pages` 폴더 자체를 한 겹 더 만들지 마세요. `source`나 ZIP 자체를 업로드하지 않습니다.
6. **Commit changes**를 누르고 GitHub Actions의 Pages 배포가 완료될 때까지 기다립니다.
7. 평소 사용하던 같은 브라우저에서 게임을 다시 열어 하단 **v1.7.0**을 확인합니다. 예전 화면이면 탭을 닫고 다시 열거나 PC에서 Ctrl+Shift+R로 새로고침합니다. 도감이 저장되어 있으므로 브라우저의 사이트 데이터/저장소를 삭제하지 마세요.
8. 상단에 **퍼즐맞추기** 메뉴가 생겼는지 확인하고, **부모님 → 퍼즐맞추기 → 퍼즐 조각 수**를 설정한 뒤 **퍼즐 설정 저장**을 누릅니다.

`index.html`만 교체하면 새 JavaScript/CSS를 찾지 못해 하얀 화면이 생길 수 있습니다. 반드시 같은 ZIP의 `assets`도 함께 올리세요.

게임 화면은 v1.7.0이고 부모님 설정의 서버 버전은 v1.6.0이어도 정상입니다. 이번 새 놀이에는 서버 변경이 없습니다. ZIP의 worker는 누적 보관용입니다. v1.6.0 그림책 기능을 아직 설치하지 않았다면 포함된 UPDATE-v1.6.0.md의 Worker 설치 절차를 먼저 적용하고, GitHub 파일은 이 v1.7.0 완성본으로 한 번만 올리세요.

## 1. 내 도감 퍼즐맞추기

- 상단 **퍼즐맞추기** 또는 첫 화면 **내 도감으로 퍼즐맞추기**를 누릅니다. 새 캐릭터나 이야기를 만들 필요가 없습니다.
- **아이 1 / 아이 2의 도감** 중 고르고, 캐릭터 사진이나 그림책 장면을 선택합니다. 먹이주기 전·후 사진과 완성된 삽화를 각각 선택할 수 있습니다. 아직 생성되지 않은 삽화는 나오지 않습니다.
- 조각을 다른 조각 위로 끌어 놓으면 두 조각이 자리를 바꿉니다. 또는 첫 조각을 누르고 두 번째 조각을 눌러 바꿀 수 있습니다. S펜, 손가락, 마우스를 지원합니다.
- 네모 조각을 맞추는 퍼즐이며 회전은 없습니다. **완성 그림 힌트**로 원본을 보고, **다시 섞기**로 다시 시작합니다. 시간 제한이나 감점은 없습니다.
- 부모님 설정에서 **9조각(3×3) / 16조각(4×4) / 25조각(5×5)**을 선택합니다. 기본은 9조각이며 이 기기의 두 아이에게 함께 적용됩니다. 설정은 새로고침 후에도 유지되고 전체 백업에 포함됩니다.
- 놀이 도중 다른 메뉴로 나가거나 페이지를 새로고침하면 퍼즐 배치는 새로 시작합니다. 원본 도감의 사진은 바뀌지 않습니다.

## 2. 그림책 장면 순서 맞추기

- 그림책의 **마지막 장**까지 넘기면 **그림책 장면 순서 맞추기**가 나옵니다. 도감에서 읽거나 크게 읽기에서도 사용할 수 있습니다. 모든 삽화가 완성된 4·6·8장 그림책에 표시됩니다. 예전 글만 있는 이야기에는 표시되지 않습니다.
- 별도 창에 모든 장면을 섞어 보여 줍니다. 그림을 아래 **1, 2, 3…** 칸으로 끌어 놓습니다. **그림 선택 → 숫자 칸 누르기**도 가능합니다.
- 태블릿 가로 화면은 한 줄로, 좁은 휴대폰 화면은 네 칸씩 줄을 바꿔 표시합니다. 각 줄에서 왼쪽부터 오른쪽, 다음 줄 순서입니다.
- 이미 놓은 그림을 다른 칸으로 옮기면 자리를 바꿉니다. 고른 그림은 **고른 그림 빼기**로 다시 위로 돌려놓을 수 있습니다.
- 모두 놓고 **순서 확인**을 누르면 맞은 칸은 초록색, 다시 볼 칸은 점선으로 알려 줍니다. 정답을 강요하거나 자동으로 다음 단계에 보내지 않습니다.
- **첫 장 힌트**를 부모님이 읽어주거나 둘이 번갈아 한 장씩 놓아도 좋습니다. 오늘은 하지 않고 책만 읽어도 됩니다. 놀이 창을 닫으면 배치는 초기화됩니다.

두 놀이 모두 이미 저장된 그림만 사용하며 추가 이미지·텍스트 API 요청이나 비용이 없습니다. 원본 사진, 이야기, 손글씨와 생성 횟수는 변경하지 않습니다.

## 3. 영상 만들기 준비

합체캐릭터 완성 화면과 **내 도감 → 캐릭터 상세**의 사진 아래에 **영상 만들기 준비 · 부모님과**를 추가했습니다.

1. 인사말을 확인하거나 수정합니다. 기본값은 **연우야 안녕! 연아야 안녕!**입니다.
2. **영상 요청문 복사**를 누릅니다. 약 8초 동안 손 흔들기 → 간단한 춤 → 웃으며 인사하는 요청문입니다.
3. **사진 공유하기**가 보이면 누릅니다. 운영체제의 공유 목록에 Gemini가 나타나면 직접 선택합니다. 사진 공유 기능이 없는 브라우저에서는 이 버튼을 숨깁니다.
4. Gemini가 공유 목록에 없거나 첨부되지 않으면 **사진 저장하기**로 저장합니다.
5. **Gemini 열기**를 눌러 부모님 계정의 동영상 만들기 화면에서 사진을 첨부하고, 복사한 요청문을 붙여 넣은 뒤 전송합니다. 링크가 앱 대신 웹으로 열릴 수도 있습니다.
6. 완성된 영상은 Gemini에서 확인하고 다운로드합니다. 이번 버전은 동영상을 게임 도감에 다시 저장하지 않습니다.

사진 공유는 사용자가 고른 앱으로 사진 파일을 전달하는 기능입니다. 게임이 Gemini를 강제로 지정하거나 생성 명령을 자동 실행하지 않습니다. 요청문은 따로 복사하며 전달할 앱에서 붙여 넣어야 합니다. 공개된 공식 안내에서 사진+명령을 외부 웹사이트에서 한 번에 자동 실행하는 연결 방식은 확인하지 못했습니다. 이 게임의 OpenAI API 비용은 생기지 않고 Gemini 구독의 사용 한도가 적용됩니다. 음성과 이름 발음, 캐릭터 유지 정도는 실제 결과를 확인해야 합니다.

2026-11-17 공식 안내를 확인했습니다. Gemini는 사진을 참고한 짧은 영상과 음성 생성을 지원하여 이 용도에 추천합니다. Sora 웹/앱은 2026-04-26 종료되었고, Claude Motion은 코드로 만드는 애니메이션 기능이므로 이 사진의 캐릭터가 자연스럽게 춤추고 말하는 용도에는 Gemini가 더 직접적입니다. 서비스 메뉴와 이용 가능 범위는 계정·지역·앱 버전에 따라 달라질 수 있습니다.
