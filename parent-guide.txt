# 꼬물꼬물 동물연구소 — 무료 서버 구성 설치 안내

준비한 구성: **GitHub Pages(화면) + Cloudflare Workers Free(그림 요청) + 태블릿 저장(도감)**.
OpenAI 이미지 생성 비용은 이미 충전한 크레딧에서 별도로 사용됩니다.

이번 파일은 배포 준비가 끝난 버전입니다. 사용자 계정에 실제 게시하거나 API 키를 등록한 상태는 아닙니다.
첫 번째 한글 게임 저장소는 그대로 두고, **새 저장소**에 두 번째 게임을 올립니다.

## 파일 구성

- `github-pages/`: GitHub에 업로드할 완성된 게임 파일. HTML, CSS, JavaScript, 동물 사진 10장, 마스코트 포함.
- `worker/cloudflare-worker.js`: Cloudflare 편집기에 통째로 붙여 넣을 서버 코드.
- `worker/schema.sql`: 횟수 기록용 데이터베이스에 한 번 실행할 코드.
- `START-HERE.html`: 이 안내를 브라우저에서 읽는 파일.
- `source/`: 나중에 게임을 수정할 때 사용하는 소스. 지금 설치할 때는 필요하지 않습니다.

사진 10장은 이미 포함되어 있습니다. 같은 사진을 다시 만들거나 등록하지 않아도 됩니다.
새 버전은 아이 이름을 공개 파일에 넣지 않고 기본값 ‘아이 1 / 아이 2’로 시작합니다. 부모님 화면에서 이름을 정해 주세요.

## 1. GitHub Pages에 두 번째 게임 올리기

1. 컴퓨터에서 GitHub의 **reaciple 계정**으로 로그인합니다.
2. https://github.com/new 에서 새 저장소를 만듭니다.
   - Repository name: `animal-letter-lab`
   - Visibility: **Public** (공개 저장소의 GitHub Pages 무료 사용)
   - Add a README를 켜고 Create repository를 누릅니다.
3. 압축을 풉니다. 새 저장소에서 **Add file → Upload files**를 누릅니다.
4. `github-pages` 폴더를 열어 **그 안의 파일과 폴더 전체**를 끌어다 놓습니다.
   - 저장소 맨 위에 `index.html`, `assets`, `animals`, `mascot.png` 등이 보여야 합니다.
   - `github-pages` 폴더 자체를 감싸서 올리지 마세요.
   - ZIP 파일만 업로드해서는 게임이 실행되지 않습니다.
   - 숨김 파일 `.nojekyll`이 보이지 않아 빠져도 이 파일 구성은 동작합니다.
5. Commit changes를 누릅니다.
6. 저장소 **Settings → Pages**에서:
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)**
   - Save
7. 게시가 끝나면 아래 주소로 접속합니다. 몇 분 걸릴 수 있습니다.
   - https://reaciple.github.io/animal-letter-lab/
8. 홈 화면과 동물 사진을 확인합니다. 아직 그림 생성 연결 전이므로 새 합체 그림은 다음 단계를 마친 뒤 만듭니다.

공개되는 것은 게임 코드와 동물 카드 사진입니다. 아이 이름·손글씨·생성한 도감은 GitHub에 업로드하지 않습니다.
API 키, 가족 연결 코드, 개인 도감 백업 파일도 저장소에 올리지 마세요.

## 2. 게임에서 가족 연결 코드 만들기

1. 새 게임의 오른쪽 위 **부모님**을 누릅니다. 확인 문제 7 + 5에 `12`를 입력합니다.
2. **그림 생성 연결 → 연결 코드 만들기 → 코드 복사**를 누릅니다.
3. 이 코드는 64자리의 무작위 값입니다. 본인만 볼 수 있는 곳에 잠시 보관합니다.
4. 이 코드는 아래 Cloudflare의 `FAMILY_TOKEN`에 등록할 값입니다.

**OpenAI API 키와 가족 연결 코드는 서로 다릅니다.**
- OpenAI API 키: OpenAI가 발급한 키. Cloudflare에만 등록합니다.
- 가족 연결 코드: 우리 게임이 서버를 사용할 때 확인하는 암호. 위 버튼으로 만듭니다.

## 3. Cloudflare에서 무료 Worker 만들기

1. https://dash.cloudflare.com/ 에서 개인 계정을 만들거나 로그인합니다.
2. **Workers & Pages**로 들어갑니다. 화면에 따라 **Compute & AI** 메뉴 안에 있을 수 있습니다.
3. **Create application → Create Worker / Start with Hello World**를 선택합니다.
4. 이름을 `animal-letter-api`로 정하고 Deploy를 누릅니다.
5. 생성한 Worker에서 **Edit code**를 누릅니다.
6. 압축에 들어 있는 `worker/cloudflare-worker.js`를 메모장으로 엽니다.
7. 파일 내용을 전체 복사하여 Cloudflare의 기본 `worker.js` 내용을 모두 교체합니다. Deploy를 누릅니다.
8. Worker 주소를 기록합니다. 예: `https://animal-letter-api.본인계정.workers.dev`.
   - 이 예시 주소를 그대로 쓰지 말고 본인 화면에 표시되는 주소를 사용하세요.
   - 별도 도메인을 구매할 필요가 없습니다.

**Workers Free 요금제를 유지합니다.** 이 게임에는 Workers Paid, R2, Cloudflare Images, 유료 도메인이 필요하지 않습니다.

## 4. 무료 D1에 ‘요청 횟수 장부’ 만들기

이 장부는 새로고침이나 다른 브라우저로 접속해도 생성 한도를 지키기 위한 작은 기록입니다.
그림·사진·아이 이름·손글씨·프롬프트는 저장하지 않습니다. 요청 번호, 한국 날짜, 요청 시간, 처리 상태만 기록합니다.

1. Cloudflare의 **Storage & Databases → D1 SQL Database → Create database**로 들어갑니다.
2. 이름을 `animal-letter-counter`로 정하고 생성합니다.
3. 생성한 데이터베이스의 **Console**을 엽니다.
4. `worker/schema.sql`의 내용을 붙여 넣고 Execute/Run을 누릅니다.
   - 여러 문장 실행이 안 되면 세미콜론 단위로 나누어 실행합니다.
   - `requests` 테이블과 인덱스가 생성됩니다. 같은 코드를 다시 실행해도 기존 기록을 지우지 않습니다.
5. **Workers & Pages → animal-letter-api → Bindings → Add binding → D1 database**로 이동합니다.
6. Variable name을 정확히 `DB`로 입력하고, 방금 만든 `animal-letter-counter`를 선택합니다.
7. 저장/배포합니다.

D1도 Free 한도 내에서 사용하며, 무료 한도를 넘으면 요청이 중단되는 방식입니다. 가정용 횟수 기록은 매우 작습니다.

## 5. API 키와 연결 코드를 Cloudflare에 등록

Worker의 **Settings → Variables and Secrets → Add**에서 다음 항목을 등록합니다.
화면에 따라 변수 변경 후 **Deploy**를 한 번 더 눌러야 합니다.

| 이름 | 종류 | 넣을 값 |
|---|---|---|
| `OPENAI_API_KEY` | **Secret** | 이미 OpenAI에서 발급받은 API 키 |
| `FAMILY_TOKEN` | **Secret** | 2단계에서 만든 64자리 가족 연결 코드 |
| `ALLOWED_ORIGIN` | Text | `https://reaciple.github.io` |
| `MAX_DAILY_REQUESTS` | Text | `4` |
| `MAX_MONTHLY_REQUESTS` | Text | `60` |

- 변수 이름은 대소문자까지 정확히 입력합니다.
- `ALLOWED_ORIGIN`에는 `/animal-letter-lab/` 같은 경로나 마지막 `/`를 붙이지 않습니다.
- API 키는 채팅, 게임 입력칸, GitHub, `worker.js` 코드 안에 붙이지 않습니다.
- 하루·월 한도는 두 아이 합산이며 한국 시간 기준입니다. 월 한도는 매월 1일 초기화되는 집계 방식입니다.
- 실패하거나 결과를 확인하지 못한 요청도 한도에 포함합니다.
- 이 횟수 제한은 이 Worker에만 적용됩니다. 같은 API 키를 다른 프로그램에서 사용한 비용까지 제한하지 않습니다.
- 처음에는 `4`와 `60`을 그대로 쓰세요. 필요할 때만 Cloudflare에서 변경합니다. 코드상 최대치는 하루 20회·월 200회입니다.

## 6. 갤럭시 탭에서 연결하기

1. 갤럭시 탭의 Chrome 또는 Samsung Internet **일반 창**에서 새 GitHub 게임 주소를 엽니다.
2. **부모님 → 그림 생성 연결**로 들어갑니다.
3. Worker 주소와 가족 연결 코드를 입력합니다. API 키는 입력하지 않습니다.
4. **저장하고 연결 확인**을 누릅니다.
5. ‘서버 연결 확인’과 오늘·이번 달 횟수가 나오면 서버 설정이 연결된 것입니다.
   - 이 버튼은 OpenAI 이미지 생성 요청을 하지 않아 API 비용이 들지 않습니다.
   - OpenAI 키 유효성, 모델 권한, 크레딧 잔액은 첫 실제 그림 생성에서 확인됩니다.
6. 아이 1·아이 2의 이름을 바꾸고 설정 저장을 누릅니다.
7. S펜만 받기를 켭니다. 글자 쓰기에서 손가락 선은 그려지지 않고 S펜으로 쓸 수 있는지 확인합니다.
8. 부모님과 함께 동물 두 마리를 고르고 글씨를 쓴 뒤 합체하기를 **한 번** 누릅니다.
9. 생성 중에는 화면을 닫거나 새로고침하지 않습니다. 결과가 나오면 이름을 적고 도감에 저장합니다.
10. https://platform.openai.com/usage 에서 해당 프로젝트의 실제 요청과 비용을 확인합니다.

기본 생성 설정은 `gpt-image-2.5-flare`, 낮은 품질, 1024×1024, JPEG 한 장입니다.
동물 이름·특징과 선택한 두 동물의 원래 사진 프롬프트를 글로 전달합니다. 카드 사진·아이 이름·손글씨는 전송하지 않습니다.
모델 이용 권한이 없다고 나오면 OpenAI 프로젝트 권한/조직 인증을 먼저 확인합니다.

## 7. 도감 보관·백업·인쇄

- 도감, 등록 사진, 설정은 **현재 기기·현재 브라우저·현재 게임 주소**에 저장됩니다.
- 컴퓨터에서 만든 도감이 태블릿에 자동으로 나타나지는 않습니다.
- 태블릿에서 Chrome과 Samsung Internet은 서로 별도의 도감입니다. 사용할 브라우저 하나를 정해 주세요.
- 부모님 화면의 **도감 전체 백업**을 누르면 사진·설정·두 아이 도감을 담은 JSON 파일을 받습니다.
- 이 백업 파일을 구글 드라이브나 컴퓨터에 보관합니다. 연결 코드와 API 키는 백업에 들어가지 않습니다.
- 복원은 **백업 파일로 복원**에서 합니다. 기존 작품은 유지하고 같은 작품은 건너뜁니다. 사진·설정은 백업 값으로 적용합니다.
- 브라우저 데이터를 지우거나 게임 주소를 변경하기 전에는 꼭 백업합니다.
- 이전 비공개 사이트에서 만든 ‘버전 1’ 도감 백업이 있다면 작품을 가져올 수 있습니다. 이전 도감이 자동으로 옮겨지지는 않습니다.
- 완성된 그림은 이름 짓기 화면에서 별도로 다운로드할 수 있습니다.
- 작품의 **종이 도감 인쇄하기**를 누르면 A4 학습지가 나옵니다. 태블릿 인쇄가 불편하면 PDF로 저장하거나 백업을 컴퓨터에서 복원해 인쇄하세요.

## 연결이 안 될 때

| 현상 | 확인할 것 |
|---|---|
| GitHub 페이지 404 | Pages 설정, main/(root), 저장소 맨 위의 index.html, 게시 완료 여부 |
| Worker 주소를 직접 열면 접근 오류 | 정상입니다. 게임의 연결 확인 버튼을 사용하세요. 서버는 등록된 게임의 인증 요청만 받습니다. |
| 가족 연결 코드 오류 | 게임의 코드와 Cloudflare FAMILY_TOKEN 값이 같은지 확인 |
| DB 연결·테이블 설정 오류 | DB 바인딩 이름, D1 선택, schema.sql 실행 여부 확인 |
| 연결 확인은 되지만 이미지 생성 실패 | OpenAI 키, 크레딧, 모델 권한 확인 |
| 오늘·이번 달 한도 도달 | 실패 요청도 포함됩니다. 부모님 화면에서 연결 확인을 눌러 서버 횟수 확인 |
| 연결이 끊겨 결과 미확인 | 자동 재생성하지 않습니다. OpenAI 사용량을 확인한 뒤 새 요청 여부 결정 |
| 화면을 닫은 뒤 그림이 없어짐 | 서버에 이미지를 저장하지 않아 응답을 받기 전 닫으면 복구할 수 없습니다. 비용이 발생했을 수 있습니다. |
| 사진이 안 보임 | github-pages 안의 animals 폴더를 함께 업로드했는지 확인 |
| 기록이 없어 보임 | 원래 쓰던 기기·브라우저·게임 주소인지 확인하고 백업 복원 |

## 검증 범위

배포 전 빌드, 요청 인증·중복 방지·횟수 제한, 브라우저 저장·백업·복원은 제공된 검증 결과를 참고하세요.
실제 Cloudflare 계정 배포, 사용자 API 키로 유료 이미지 생성, 실물 갤럭시 탭 S펜·프린터 동작은 설치 후 확인해야 합니다.
