# v1.2.0 — 귀여운 동물 10종 추가

강아지, 고양이, 수달, 다람쥐, 알파카, 오리, 햄스터, 미어캣, 펭귄, 병아리를 추가했습니다. 기존 10종과 함께 총 20종을 선택하고 이름을 듣고 따라 쓰며 합체할 수 있습니다.

## 기존 사용자 적용 순서
1. 현재 게임의 부모님 화면에서 도감 전체 백업을 받습니다.
2. `animal-letter-lab-update-v1.2.0.zip`을 풉니다.
3. Cloudflare의 기존 Worker → Edit code에서 `worker/cloudflare-worker.js`의 전체 내용으로 교체하고 Deploy합니다. 기존 API 키, 가족 연결 코드, 환경 변수, D1 DB는 그대로 사용합니다. SQL 실행은 필요 없습니다.
4. GitHub의 현재 게임 저장소 → Add file → Upload files에서 `github-pages` **안의** `index.html`, `assets` 폴더, `parent-guide.txt`를 저장소 맨 위에 올리고 Commit changes합니다. `github-pages`라는 상위 폴더째 올리지 마세요. 기존 animals 폴더와 마스코트 파일은 보존합니다. 이전 assets 파일은 남아 있어도 됩니다.
5. 게시가 끝나면 같은 게임 주소를 새로고침합니다. 하단 v1.2.0 확인. 부모님 → 저장하고 연결 확인을 눌러 서버 v1.2.0 · 동물 20종 표시 확인. 이 연결 확인은 그림을 생성하지 않습니다.
6. `NEW-ANIMAL-PROMPTS.txt`에서 원하는 동물의 블록 전체를 복사해 사진을 한 장씩 생성합니다. 10마리를 한 이미지에 넣지 마세요. 사진 생성은 사용자님이 진행하며, 이번 ZIP에는 새 사진이 포함되어 있지 않습니다.
7. 실제로 게임할 탭의 부모님 → 동물 사진 준비에서 각 동물에 해당하는 사진을 등록합니다. 등록 전에는 동물 기호가 표시되며 합체 기능은 사용할 수 있습니다. 미어캣은 임시 발바닥 기호로 표시됩니다.
8. 새 사진 등록 후 전체 백업을 다시 받아 보관합니다.

## 사진을 PC에서 만든 경우
- 사진 파일을 탭으로 옮겨 탭의 게임에서 등록하거나, PC 게임에서 등록한 뒤 전체 백업 JSON을 탭 게임에서 복원하세요.
- 부모님 화면의 사진 등록은 **그 기기·브라우저에만** 저장됩니다. 다른 사람에게 사이트 주소를 공유해도 새 사진이 자동으로 전달되지는 않습니다.
- 새 사진을 모든 접속자에게 기본 제공하려면 사이트 배포 파일에 포함하는 후속 작업이 필요합니다. PNG 이름은 프롬프트 문서의 권장 이름을 사용하면 구분하기 쉽습니다. 이번 버전에서는 GitHub에 사진 파일만 추가하는 것으로 자동 등록되지는 않습니다.
- 같은 사이트 주소와 브라우저를 유지하세요. 사이트 데이터 삭제는 도감과 설정을 지울 수 있습니다.

## 이번 버전의 동작
- 기존 도감, 아이 설정, 사진, 연결 설정, 삭제 기능, 오늘 횟수 초기화를 유지합니다.
- 기존 10종 사진 백업을 복원할 수 있습니다. 신규 사진이 없는 상태에서도 백업이 됩니다. 등록된 신규 사진은 백업에 포함됩니다.
- 사진 프롬프트는 부모님 화면에서도 전체 20종/추가 10종으로 다운로드할 수 있습니다.
- 합체 API는 계속 **텍스트만** 전송합니다. 이번에 제공한 새 사진 프롬프트와 각 종의 특징을 합체 요청에도 그대로 사용합니다.
- 이미지 참조 합체, 옷 입히기, 액세서리 꾸미기는 이번에 추가하지 않았습니다. 별도 기획 문서에서 다음 개발 단계를 제안합니다.
- 새 동물을 쓰려면 화면과 Worker를 **둘 다** 업데이트해야 합니다. 이전 Worker는 새 동물 ID를 거부합니다.

실제 사용자 사이트 배포는 아직 확인되지 않았습니다. 적용 후 버전과 동작을 알려 주세요.
