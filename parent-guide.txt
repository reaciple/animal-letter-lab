캐릭터연구소 v1.15.0 · 2026-11-25

적용 방법
1. 평소 사용하던 태블릿에서 부모님 → 도감 전체 백업을 받아 두세요. 브라우저 사이트 데이터는 지우지 마세요.
2. 기존 Cloudflare Worker → Edit code에서 worker/cloudflare-worker.js 전체로 교체 → Deploy. 한 번에 붙여넣기 어렵다면 편집기를 비운 뒤 worker/paste-parts/01.txt부터 번호순으로 이어 붙여 한 번만 Deploy 합니다. 기존 DB 바인딩과 비밀 키는 그대로 두세요. 새 설정 테이블은 자동 생성합니다.
3. 기존 GitHub Pages 배포 위치에 github-pages 폴더 자체가 아니라 안의 내용(index.html, assets, forest-cup 등)을 한 번에 올립니다. 캐릭터 사진을 다시 등록할 필요 없습니다.
4. 원래 게임 주소에서 새로고침 → 홈 하단 v1.15.0 확인 → 부모님 → 실시간 그림 만들기 → 하루 최대 요청 수에 8 입력 → 생성 설정 저장. ‘서버 한도 8회’를 확인하세요. 연결되어 있어야 저장됩니다. 이 설정은 합체와 먹이 사진을 합산하며 두 아이와 같은 Worker의 모든 기기에 적용됩니다. 기존 MAX_DAILY_REQUESTS는 처음 사용할 기본값으로만 쓰고, 부모님이 저장하면 저장값이 우선합니다(1~20). 월 한도 숫자는 기존 Cloudflare 설정대로입니다.

게임 한도
- 오늘 요청 횟수 초기화: 오늘 합체·먹이 그림만.
- 오늘 그림책 횟수 초기화 · 원고와 삽화: 오늘의 원고와 삽화를 함께. 이미 저장한 원고·페이지는 도감에서 이어 만들 수 있습니다.
- 이번 달 전체 요청 횟수 초기화: 이번 달 합체·먹이 그림, 원고, 삽화 모두. 오늘 횟수는 그대로입니다. 일·월 모두 막혔다면 둘 다 해당 기간을 초기화하세요.
- 초기화는 게임 카운터만 다시 열고 이미 발생한 비용, 기존 작품과 요청 ID는 보존합니다. 생성 중에는 완료 후 초기화하세요. 표시는 한국 시간 기준입니다.
- 한도 오류는 원고/삽화/캐릭터 사진, 일/월을 나누어 표시합니다. 선불 크레딧 소진, OpenAI의 지출 제한, 요청 속도 제한은 별도입니다.

API 잔액
부모님 → 남은 요청과 OpenAI 잔액에서 게임의 오늘·이번 달 잔여 횟수를 확인하세요. 실제 달러 잔액은 ‘OpenAI 실제 잔액 보기’로 로그인해 게임 프로젝트가 속한 조직의 Billing overview에서 확인하세요.
https://platform.openai.com/settings/organization/billing/overview
프로젝트별 사용 금액: https://platform.openai.com/usage
게임에 표시할 금액은 ‘마지막으로 확인한 잔액 메모’에 직접 기록할 수 있습니다. 확인 시각을 함께 보관하고 자동 차감·갱신하지 않습니다. 관리자 키나 플랫폼 로그인 정보를 게임에 입력할 필요가 없습니다.

경주와 그림책
- 선수 약 16% 축소, 관중 약 13% 확대. 새싹 운동화로 1초당 1.8회 입력 기준 주행 약 25초(출발 준비 제외).
- 사진 윤곽과 색을 사용해 방향별로 입체감을 그립니다. 커브에서 옆·뒤가 보이고, 추가 이미지 생성 없이 기존 도감에도 적용됩니다. 등은 실제 뒷면 사진이 아니라 추정한 모습입니다.
- 책이 완성되면 큰 읽기 화면이 열립니다. 도감에서는 ‘그림책 크게 읽기’를 누르세요. 태블릿을 가로로 두면 왼쪽은 삽화, 오른쪽은 글과 장 넘기기입니다. 그림의 위아래를 자르지 않습니다.
