캐릭터연구소 1.14.0 | 숲속 운동회와 개인 신발장

적용 순서
1. 평소 쓰던 태블릿과 브라우저의 게임에서 부모님 → 도감 전체 백업을 받으세요. 사이트 데이터를 지우지 마세요.
2. Cloudflare의 기존 Worker → Edit code에서 worker/cloudflare-worker.js로 교체하고 Deploy 합니다. 한 번에 붙여넣기 어렵다면 편집창을 비우고 worker/paste-parts/01.txt부터 마지막 번호까지 이어 붙인 다음 한 번만 Deploy 합니다. 키·한도·D1은 변경하지 않습니다.
3. 기존 GitHub Pages 배포 위치에 github-pages 폴더 안의 내용을 올리세요. 특히 assets와 새 forest-cup 폴더(상대 동물 10종과 경기장)를 함께 올리고 index.html을 마지막에 덮어쓰거나 모두 한 번에 커밋하세요. worker 폴더는 GitHub Pages에 넣지 않습니다.
4. 원래 주소에서 새로고침하고 홈 하단 v1.14.0을 확인하세요. 이미 등록한 20종의 사진은 다시 등록할 필요 없습니다.

새 합체 사진
등록한 두 장의 사진에서 각각 얼굴 특징 하나와 얼굴 밖 특징 하나 이상을 크게 반영하도록 요청합니다. 색깔이나 아주 작은 무늬만 두 번째 친구에게서 따오는 것을 피합니다. 상체를 세우고 두 발만 바닥에 붙여 선 전신을 요청합니다. 달리기 자세는 게임에서 움직임으로 표현합니다. 기존 도감 그림은 바뀌지 않습니다.

경주
운동장과 관중 276명을 원근이 있는 그림으로 구성하고, 상대 10종은 입체 모형의 8가지 달리는 자세로 제작했습니다. 새로 이미지를 만들거나 API를 호출할 필요가 없습니다. Space·Enter 또는 화면 발판을 계속 누르면 달립니다. 새싹 운동화·초당 2.5회 기준 주행 약 25초입니다(출발 준비 제외). 결승선에서는 꽃가루와 리본 연출 뒤 시상식 또는 종료를 고릅니다. 시상식에는 두 선수 모두 등장하고 1등은 금메달, 2등은 은메달을 받습니다. ‘게임 종료하기’는 게임 홈으로 갑니다. 횟수를 강제로 잠그지는 않습니다.

지갑과 신발장
- 그림책 순서를 모두 맞히면 그 책을 만든 캐릭터에 5~10원이 한 번 적립됩니다. 같은 판의 중복 터치·저장 재시도는 추가 적립을 하지 않습니다. 독립적으로 다시 연 판은 새 놀이입니다.
- 같은 아이, 같은 이름이나 재료로 만들어도 새로 합체한 작품이면 별도 지갑·신발장입니다. 먹이 주기 전·후 사진만 같은 캐릭터로 취급합니다. 구매, 착용, 판매, 환불 모두 선택한 캐릭터에만 적용됩니다. 원래 코인 달리기의 장비 지갑은 그대로 별도입니다.
- 예전에 공유하던 한 켤레는 구매자 기록이 있으면 구매한 캐릭터에게, 구매자 기록이 없고 착용자가 한 명이면 그 착용자에게 남깁니다. 주인이 불분명하면 가게에서 ‘이전 ○○ 운동화 받기’를 한 캐릭터로 딱 한 번 선택할 수 있습니다. 수령해도 자동 판매하거나 잔액을 올리지 않습니다. 이전 거래를 취소하거나 과거 잔액을 추정해 차감하지 않습니다.
- 전체 백업 v11이며 예전 백업도 읽습니다. 빈 기기에 복원하면 백업 지갑이 복원됩니다. 이미 사용 중인 캐릭터의 현 지갑과 신발장 기록이 예전 백업보다 우선합니다.
