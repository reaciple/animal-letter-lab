# 캐릭터연구소 v1.18.0 · 가족 경주 지갑과 기기 이전

**v1.17에서 업데이트:** 평소 쓰는 브라우저에서 기존 도감을 먼저 백업하세요. 업데이트 ZIP을 풀고 github-pages 안의 파일·폴더를 기존 GitHub 저장소의 index.html과 같은 위치에 올려 함께 커밋하세요. 배포 후 같은 게임 주소를 새로고침하고 홈 하단 v1.18.0을 확인하세요. 사이트 데이터를 지우지 마세요. Cloudflare Worker, 키, DB 변경은 없습니다. 새 선수 사진도 필요하지 않습니다.

## 매일의 놀이
1. 부모님 → 아이별 경주 지갑에서 연아 또는 연우의 **코인 초기화**를 누르고 확인하면 해당 아이의 경주 잔액만 0원이 됩니다. 자동으로 매일 초기화되지는 않습니다. 신발, 도감, 다른 아이의 돈, 별도 코인 달리기의 장비 지갑은 남습니다.
2. 어느 도감 친구의 그림책으로 순서 맞추기를 해도 그림책을 소유한 아이의 지갑에 5~10원이 적립됩니다. 같은 판의 중복 지급은 막습니다. 기존 캐릭터별 잔액과 이전 공용 잔액은 해당 아이의 돈으로 합산됩니다.
3. 동물 경주 → 아이 → 등록된 선수만 선택합니다. 운동화 가게 상단의 아이 이름과 잔액을 확인하세요. 신발은 선수별로 착용하고, 판매한 금액은 아이 지갑으로 돌아갑니다.
4. 이름은 내 도감 → 해당 친구 → **캐릭터 이름 짓기 · 수정**에서 나중에 적어도 됩니다. 같은 친구의 첫 그림/식사 그림, 등록된 경주 선수 이름이 함께 바뀝니다. 손글씨와 이미 만든 그림책 내용은 바뀌지 않습니다.
5. 부모님 → 경주 선수 만들기에서 그림 아래의 **옆모습/앞모습/뒷모습**을 눌러 큰 화면에서 한 방향씩 확인하세요. 일시 정지와 재생을 지원합니다.

## 다른 기기에서 이어 하기
- 쓰던 기기: 부모님 → **게임 전체 백업 · 복원** → **전체 백업 받기** → 새 암호를 두 번 입력 → **암호화 파일 다운로드**. .forest 파일과 암호를 각각 보관하세요. 별도 앱이나 계정이 필요하지 않습니다.
- 새 기기: 같은 게임 주소(v1.18 이상) → 부모님 → **게임 전체 백업 · 복원** → **새 기기에 복원** → .forest 파일과 암호 → **백업 확인하고 복원**. 작품 수를 확인하고 교체에 동의하면 게임이 다시 열립니다.
- 도감, 등록 사진·경주 선수 시트, 그림책과 질문, 부모 설정·저장한 프롬프트, 지갑·신발·장비, 기기에 저장한 연습 및 진행 기록, Worker 주소·가족 연결 코드가 포함됩니다. 생성 요청을 다시 보내지 않습니다. OpenAI API 키·서버 사용량은 Cloudflare에 그대로 있습니다. 새 기기에서도 같은 서버를 씁니다.
- 이 방식은 **백업한 시점으로 이 브라우저의 게임 전체를 교체**합니다. 두 기기를 실시간으로 동기화하지 않습니다. 암호를 잊으면 복원할 수 없습니다. 기존 도감 JSON은 **도감 백업과 합치기**에서 계속 사용할 수 있습니다.
