# 꼬물꼬물 동물연구소 v1.5.2 · 2026-11-13

## 적용 방법
이번 누적 업데이트만 적용하면 됩니다. 기존 게임의 부모님 화면에서 도감 전체 백업을 먼저 받으세요.
1. animal-letter-lab-update-v1.5.2.zip을 풀어 주세요.
2. Cloudflare → 기존 게임 Worker → Edit code에서 worker/cloudflare-worker.js 전체 내용으로 교체하고 Deploy합니다.
3. 기존 API 키·가족 연결 코드·DB 바인딩은 유지합니다. 새 키나 DB는 필요 없습니다. 이야기 초기화 테이블은 자동 생성됩니다.
4. GitHub의 현재 게임 저장소 → Add file → Upload files에서 github-pages 폴더 안의 index.html, assets 폴더, 안내 파일을 기존 index.html과 같은 위치에 업로드하고 Commit changes합니다. github-pages 폴더 자체나 source/worker는 올리지 마세요. 기존 이미지 폴더는 삭제하지 마세요.
5. 배포가 끝나면 기존 게임 주소를 새로고침합니다. 하단 v1.5.2와 부모님 화면의 연결 확인에서 서버 버전을 확인하세요. 브라우저 사이트 데이터는 지우지 마세요.

## 새 놀이 순서
먹이 선택과 글자쓰기 → 먹이 주기 · 그림 만들기 → 먹는 그림 완성 → 이름 손글씨 쓰기와 텍스트 입력 → 이야기 생성하기 → 이야기와 질문 읽기 → 이름 저장하고 도감으로.

먹는 그림이 완성돼도 이야기는 자동 생성되지 않습니다. 이야기 생성하기를 누르면 현재 입력한 이름과 손글씨를 먼저 도감에 저장하고, 그 캐릭터 이름을 담아 GPT에 요청합니다. 별도로 이름 저장 버튼을 먼저 누를 필요는 없습니다. 이름을 빈칸으로 두면 입력 안내가 나옵니다. 손글씨를 OCR로 읽는 방식이 아니므로 이야기에는 텍스트 입력란의 이름이 사용됩니다. 손글씨는 기기에 보관하고 캐릭터 이름 텍스트는 OpenAI에 전달합니다. 아이 프로필 이름과 손글씨는 이야기 API에 보내지 않습니다.

이야기를 만들지 않고 이름만 저장하고 도감으로 가도 됩니다. 나중에 도감의 먹이주기 후 사진에서 이름을 확인하고 이야기 생성하기를 누를 수 있습니다. 이미 완성된 이야기는 그대로 보관하며 이름을 바꾼다고 기존 이야기까지 다시 생성되지는 않습니다. 이전 버전의 진행 중 요청 결과를 복구하는 경우에는 그때 요청한 이름/내용을 그대로 받습니다.

## 오늘 이야기 요청 횟수 초기화
부모님 → GPT 이야기와 질문 → 오늘 이야기 요청 횟수 초기화 → 확인.
오늘의 이야기 제한용 횟수만 0으로 다시 시작합니다. 두 아이와 같은 서버를 사용하는 기기에 함께 적용됩니다. 월 누적 횟수·기존 API 비용·저장한 이야기·그림 횟수는 바뀌지 않습니다. 이야기 생성이 진행 중이면 초기화를 막습니다. 월 한도까지 도달했다면 오늘 횟수를 초기화해도 월 한도는 유지됩니다.

## 동화의 방향
5~6살이 이해하는 그림책 수준으로, 처음에 누가 어디에서 무엇을 하려는지 분명히 소개합니다. 한 장소와 한 가지 작은 문제를 중심으로 원인→행동→결과가 이어집니다. 조연은 최대 한 명이며 복잡한 비유, 혼잣말 역할극, 갑자기 말하는 사물, 꿈과 현실의 혼동을 피합니다. 앞서 보여 준 단서로 이해할 수 있는 유쾌한 반전을 요청합니다. 질문은 기억·마음·상상·놀이 4개를 유지하며 구체적인 장면과 행동에 연결합니다. 생성 결과의 재미와 난이도는 작품마다 다를 수 있습니다.

기존 이야기 길이(1~2분/3~4분/5~6분) 설정은 유지합니다. 새 이야기부터 적용되며 저장된 이야기는 바뀌지 않습니다.

## 저장과 비용
그림은 이야기보다 먼저 도감에 저장됩니다. 이름·손글씨·이야기·질문도 기기 브라우저의 도감과 전체 백업에 포함됩니다. 이야기 실패 시 그림은 남고, 결과 확인 또는 명시적인 재시도를 할 수 있습니다. 새 이야기 버튼 요청에만 텍스트 API 비용이 발생하며 저장된 이야기 열람에는 비용이 없습니다. 실패/응답 유실에도 비용이 발생했을 수 있으므로 먼저 이전 요청 결과를 확인하세요.
Cloudflare D1은 요청 장부와 이야기 복구용 사본을 보관하며 도감 그림의 서버 백업은 아닙니다. 기기 간 자동 동기화는 없으니 전체 백업을 보관하세요.

## 검증
빌드·TypeScript·자동 테스트35개 통과. 브라우저 모의응답으로 수동 생성 전 요청0회, 몽실이 입력 후 요청1회/이름 전달, 도감 이름 저장 확인. 실제 유료 API 및 사용자 운영 사이트 배포는 수행하지 않았습니다.
