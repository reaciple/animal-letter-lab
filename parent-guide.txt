캐릭터연구소 1.13.0 · 숲속 운동회 30초 달리기

설치 (기존 게임 주소 그대로)
1. 게임의 부모님 화면에서 도감 전체 백업을 먼저 받습니다. 브라우저의 사이트 데이터를 삭제하지 마세요.
2. Cloudflare의 기존 Worker에서 Edit code → worker/cloudflare-worker.js 전체 내용으로 교체 → Deploy. 길어서 붙여넣기가 어렵다면 편집기를 비운 뒤 worker/paste-parts의 01.txt부터 마지막 번호까지 같은 창에 순서대로 이어 붙이고 마지막에 한 번만 Deploy 합니다. 두 새 캐릭터의 식별자가 추가되어 Worker도 교체해야 합니다. API 키·사용 한도·D1은 변경하지 않습니다.
3. GitHub의 기존 animal-letter-lab 저장소에서 기존 Pages 배포 위치에 github-pages 폴더 *안의 내용*을 덮어씁니다. assets를 먼저 올리고 index.html을 마지막에 올리거나, 한 번에 함께 커밋하세요. worker/와 source/는 GitHub Pages에 올리지 않습니다.
4. 평소 사용하던 태블릿 브라우저에서 기존 주소를 새로고침하고 홈 하단의 v1.13.0을 확인합니다.
5. character-prompts-v1.13.0.txt에서 각 제목 아래 본문만 사용해 사진을 한 장씩 생성하고, 부모님 → 캐릭터 사진 준비 → 도라에몽 / 마조리카 카드에 각각 등록하세요. 파일 이름은 자유입니다. 나머지 18종은 다시 등록하지 않습니다. 스티치·엘모는 새 합체 목록에서만 빠지며 기존 사진·도감·그림책·지갑은 유지됩니다.

놀이
- 순서가 맞는 그림 위에 별빛이 잠깐 피고 사라집니다. 숫자에는 체크를 남기지 않고 모두 맞혔을 때의 축하와 주인공의 5~10원 적립은 유지합니다.
- 운동화는 5~10원, 속력 보너스는 +6~+11. 맨발 4 + 새싹 6 = 치타와 같은 10입니다. 같은 아이의 캐릭터들은 신발을 공유하되, 살 때는 선택한 캐릭터의 지갑을 사용합니다. ‘팔기’ 확인 시 구매 금액 전부를 구매 캐릭터에게 돌려주고, 같은 신발을 착용한 친구들은 맨발이 됩니다. 구매자 기록이 없는 예전 신발은 현재 선택한 캐릭터 지갑으로 환불합니다. 확인창에 지갑 이름과 금액이 표시됩니다.
- 상점 바로 위에 지갑 잔액을 표시합니다. 살 수 있는 가격은 진한 버튼으로, 부족한 가격은 비활성 버튼과 부족액으로 표시합니다.
- 운동장 한 바퀴는 320m입니다. 선수 근접 카메라, 순위, 남은 거리, 로켓·폭죽 등 6종 즉시 아이템 효과를 사용합니다. PC는 Space/Enter, 태블릿은 왼발/오른발. 보통 박자로 달릴 때 약 30초이며 누르기를 멈추면 시간이 더 걸립니다. 카운트다운은 별도입니다.
- 전체 백업 v10에는 판매 기록이 포함됩니다. v1~9도 복원할 수 있습니다.
