# 캐릭터연구소 v1.5.4 업데이트

## 변경 사항
- 기존 캐릭터 10종은 유지하고, 강아지·고양이·수달·다람쥐·알파카·오리·햄스터·미어캣·펭귄·병아리를 새 선택 목록에서 제외했습니다.
- 피카츄, 이브이, 꼬북이, 고라파덕, 푸린, 무민, 설리, 그루트, 뽀로로, 루피를 추가했습니다. ‘꼬북이’ 표기는 요청하신 그대로입니다.
- 두 참조 사진의 눈 모양과 간격, 코·주둥이, 입, 볼, 이마, 얼굴형을 섞어 하나의 자연스러운 얼굴로 만들도록 요청합니다. 얼굴 반쪽 붙이기와 눈·코·입 중복은 피하도록 했습니다.
- P1의 사진 중심 합체 방식과 D1 오류 진단을 유지합니다. 현재 사진 합체 요청에는 캐릭터 이름·고정 특징·원본 파일명을 넣지 않습니다. 이야기에는 선택한 캐릭터 정보가 계속 사용됩니다.
- 화면·도감·인쇄·설정·다운로드 문구의 ‘동물’을 ‘캐릭터’로 변경했습니다.
- 기존 사진, 도감, 이야기, 설정과 연결 정보는 유지합니다. 이전 동물로 만든 작품의 이름 조회, 백업 복원, 먹이주기도 지원합니다. 저장소 이름이나 내부 ID를 바꾸지 않았습니다.

## 업데이트 순서
1. 현재 게임의 부모님 화면에서 ‘도감 전체 백업’을 먼저 내려받으세요.
2. Cloudflare에서 기존 Worker → Edit code로 들어가 ZIP의 worker/cloudflare-worker.js 내용 전체로 교체한 뒤 Deploy 하세요. API 키·변수·DB는 그대로 사용합니다. DB를 새로 만들거나 초기화하지 마세요.
3. GitHub animal-letter-lab 저장소에서 Add file → Upload files를 열고 ZIP의 github-pages 폴더 **안의 모든 파일과 폴더**를 기존 배포 위치에 올려 Commit changes 하세요. index.html만 올리지 말고 assets 폴더도 꼭 함께 올리세요. github-pages 폴더 자체를 한 겹 추가하지 마세요. 기존 Pages 설정은 그대로 둡니다.
4. GitHub Actions의 배포 완료 후 기존 게임 주소를 새로고침합니다. 하단 v1.5.4, 부모님 → 저장하고 연결 확인의 서버 v1.5.4를 확인하세요. 이전 화면이면 탭을 닫았다 다시 열거나 캐시를 무시한 새로고침을 하세요. 사이트 데이터/저장소는 지우지 마세요.
5. 부모님 → 캐릭터 사진 준비에서 새 캐릭터 10개의 각 이름 칸에 준비한 사진을 등록하세요. 파일명은 자유입니다. 기존 캐릭터 사진은 재등록할 필요 없습니다. 사진은 현재 기기·브라우저에 저장됩니다.
6. 새 놀이에서 두 캐릭터를 선택하고 글자를 쓴 뒤 합체해 보세요. 이전 진행이 남았다면 ‘진행 초기화 · 새 놀이’를 사용하세요. 도감은 지워지지 않습니다.

source 폴더는 개발·다음 업데이트용 원본입니다. GitHub Pages나 Worker에 올릴 필요는 없지만 ZIP과 함께 보관하세요.

## 확인한 범위
자동 테스트 40개 통과, 배포용 빌드 성공, 브라우저에서 제목·메인 문구·20개 캐릭터 선택 목록 확인. 실제 OpenAI 유료 생성이나 사용자 사이트 배포는 수행하지 않았습니다. 얼굴 혼합 정도와 생성 성공 여부는 실제 결과에서 확인해야 하며 매번 동일하지 않을 수 있습니다.
