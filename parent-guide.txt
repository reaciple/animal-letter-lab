# v1.3.0 — 사진 합체, 꾸미기, 집, 먹이주기

## 적용 순서
1. 아이들이 사용하던 탭의 기존 게임에서 부모님 → 도감 전체 백업을 받습니다. 업데이트 전 백업도 보관하세요.
2. 업데이트 ZIP을 풉니다. Cloudflare의 기존 Worker → Edit code에서 `worker/cloudflare-worker.js` 전체로 교체하고 Deploy합니다. 기존 OPENAI_API_KEY, FAMILY_TOKEN, DB 바인딩과 한도 설정을 유지합니다. 새 DB나 SQL 실행은 필요 없습니다.
3. GitHub의 현재 게임 저장소 맨 위에서 Add file → Upload files를 누릅니다. ZIP의 `github-pages` 안에 있는 파일과 assets 폴더를 올리고 기존 배포 브랜치에 Commit changes합니다. github-pages 바깥 폴더째 올리지 마세요. 기존 animals 폴더와 마스코트를 보존합니다.
4. 게시 완료 후 기존 주소를 새로고침해 하단 v1.3.0 확인. 부모님 → 저장하고 연결 확인에서 서버 v1.3.0 확인. 서버가 이전 버전이면 새 이미지 요청을 차단하고 업데이트를 안내합니다.
5. `ITEM-PROMPTS-v1.3.0.txt`에서 각 항목의 프롬프트 전체를 복사하여 한 장씩 생성합니다. 30개를 한 이미지에 넣지 마세요.
6. 부모님 → 꾸미기·집·먹이 사진 준비에서 해당 사진을 등록합니다. 필요한 항목부터 등록해도 됩니다. 동물 사진 20종은 기존 등록 사진을 사용합니다. 새 동물 사진을 아직 등록하지 않았다면 동물 사진 준비에서 먼저 등록하세요.
7. 실제 탭에서 두 동물과 등록된 항목으로 첫 그림을 생성해 확인합니다. 이어서 먹이주기를 하면 별도 유료 요청 1회가 더 발생합니다. 사진 등록과 연결 확인에는 이미지 생성 API 비용이 들지 않습니다.
8. 새 사진 등록 후 전체 백업을 다시 받습니다. 새 백업 버전3은 이전 게임 버전에서 복원할 수 없으므로 게임부터 업데이트합니다. 버전1·2 백업은 새 게임에서 복원 가능합니다.

## 놀이 순서
동물 두 마리 → 옷·소품 → 색 → 집 → 첫 그림 만들기 → 먹이 선택 → 먹이 주기 또는 생략 → 이름·손글씨 → 도감·인쇄.

- 동물 두 마리는 합체의 기본 재료입니다. 동물도 각각 글자를 써야 선택됩니다.
- 옷·소품, 색, 집, 먹이는 각각 하나만 고를 수 있고 모두 ‘선택 안 함’이 있습니다. 선택 안 함에는 글자쓰기가 필요 없습니다.
- 사진을 누르면 글자쓰기 창이 열립니다. 실제로 선을 그린 뒤 ‘쓰기 완료하고 적용’을 눌러야 적용됩니다. 글자를 자동 인식·채점하는 방식은 아닙니다. 부모가 함께 확인해 주세요. 화면을 한 번 찍는 것만으로는 완료되지 않습니다.
- 부모님 설정의 ‘한 글자부터 / 동물 이름 전체’ 설정은 아이템에도 적용됩니다. 이름 전체 모드는 아이템 이름 전체를 씁니다.
- 다른 항목으로 바꾸면 새 항목의 글자쓰기를 다시 합니다. 취소하면 기존 선택이 유지됩니다.
- 첫 그림은 선택한 동물 사진2장과 소품·색·집 사진(각0~1장), 합계2~5장을 API로 보냅니다. 아이 이름과 손글씨는 보내지 않습니다.
- 먹이주기는 첫 그림과 먹이 사진, 합계2장을 보내 먹는 모습과 밝아진 표정을 새로 만듭니다. 첫 그림은 보존하고 식사 그림을 별도 저장합니다.
- 말풍선 ‘냠냠, 맛있어! 고마워!’는 한글 오류를 줄이기 위해 게임이 결과에 합성합니다. 이미지 파일 자체에 들어가므로 다운로드·백업·인쇄에도 포함됩니다.
- 먹이주기를 생략하면 첫 그림만 저장됩니다. 도감의 작품 상세에서 나중에 ‘이 친구에게 먹이 주기’를 할 수도 있습니다.
- ‘잠깐 쉬기’ 후 같은 아이를 선택하면 저장된 선택과 단계를 이어갑니다. 생성 도중에는 화면을 닫지 마세요. 응답을 받기 전 닫으면 결과를 잃을 수 있으며 비용이 발생했을 수 있습니다.
- 결과 저장만 실패한 경우 ‘받은 결과 확인·저장 다시 하기’는 저장된 결과를 사용합니다. 새 유료 요청을 자동으로 보내지 않습니다. 결과 불명 요청을 새로 시도하려면 추가 비용 확인이 필요합니다.

## 제공 항목
- 소품10: 모자, 리본, 목도리, 머리띠, 안경, 조끼, 망토, 우비, 목걸이, 가방.
- 색5: 분홍, 노랑, 파랑, 초록, 보라.
- 집10: 울타리, 동굴, 강아지 집, 고양이 집, 외양간, 나무 집, 이글루, 둥지, 연못, 텐트.
- 먹이5: 당근, 풀, 사과, 바나나, 곡식.

## 비용과 사진 보관
- 첫 그림1회, 먹이주기1회로 각각 기존 일/월 한도에 합산됩니다. 기본 하루4회면 완전한 두 번의 놀이(첫 그림+먹이주기)가 가능합니다. 다른 요청·실패 요청이 있으면 남은 횟수는 줄어듭니다.
- 이미지 입력 처리 비용이 추가됩니다. 기존 모델 gpt-image-2.5-flare, low, 1024x1024, 한 장 설정을 유지합니다. 전송할 참조 사진은 기기에서 최대768px JPEG로 축소합니다.
- 등록한 사진은 해당 기기·브라우저에 저장됩니다. PC에서 등록했다면 PC에서 전체 백업을 받은 후 탭에서 복원하세요. 사진은 사이트 공유만으로 다른 기기에 전달되지 않습니다.
- 선택하지 않은 사진은 OpenAI로 보내지 않습니다. 서버 DB에는 요청 날짜·번호·처리 상태만 남고 이미지 자체를 보관하지 않습니다.
- 상상 동물 먹이 놀이이며 실제 동물에게 먹여도 되는 음식 안내가 아닙니다.

## 확인 범위
자동 테스트와 모의 API 응답으로 확인했습니다. 실제 사용자의 API 키를 이용한 유료 편집 결과와 Cloudflare 배포 후 응답시간·CPU 사용량, 실제 S펜·프린터는 사용자 환경에서 확인해야 합니다. 이미지 편집은 원본 외형이나 소품 위치를 완벽하게 보장하지 않습니다.

이 파일 제공만으로 실제 사이트가 바뀌지는 않습니다. 화면과 Worker를 모두 적용해 주세요.
