# v1.9.0 · 그림책과 코인 달리기

v1.8.0을 사용 중이라면 이번에는 GitHub Pages만 업데이트하세요.
1. 압축을 풉니다. github-pages 폴더 안의 index.html과 assets 등 내용 전체를 기존 배포 위치에 올리고 Commit changes를 누릅니다. 폴더 자체를 한 겹 더 올리지 마세요.
2. 배포가 끝나면 원래 태블릿과 브라우저에서 같은 주소를 새로고침합니다. 첫 화면 아래 v1.9.0과 코인 달리기 메뉴가 표시됩니다. 사이트 데이터나 도감을 지우지 마세요. Cloudflare Worker와 API 키는 그대로 둡니다.

기존 그림책도 바로 새 화면에서 읽을 수 있습니다. 그림 바로 아래의 앞장/다음 장을 누르거나 그림 위에서 왼쪽(다음) 또는 오른쪽(앞장)으로 미세요. 태블릿을 가로로 놓고 크게 읽기를 누르면 그림 옆에서 글을 읽을 수 있습니다. 긴 글은 글 영역 안에서 스크롤됩니다.

코인 달리기: 아이의 도감에서 주인공을 고릅니다. 코인 하나는 10원, 코스 전체는 32개(320원)입니다. ‘지금 점프!’ 안내가 보이면 화면이나 점프 버튼을 한 번 누르세요. 나무토막에 걸리거나 구덩이에 빠지면 에너지 한 칸이 줄지만 이미 모은 돈은 유지됩니다. 에너지 세 칸이 모두 닳으면 그 자리 근처에서 충전해 바로 이어갑니다. 완주하면 그 판의 코인 수와 금액이 나옵니다. 금액은 한 판 단위이며 누적 지갑과 상점은 아직 없습니다. 추가 API 비용은 없습니다.
