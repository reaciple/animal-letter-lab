1.16을 먼저 설치할 필요 없습니다. 도감을 백업하고, 기존 Cloudflare Worker에 worker/cloudflare-worker.js 전체를 교체·Deploy하세요. 한 번에 붙이기 어렵다면 worker/paste-parts를 번호순으로 이어 붙여 한 번만 배포하세요. 기존 키와 DB는 그대로 사용합니다. GitHub Pages에는 github-pages 안의 파일과 폴더를 기존 index.html 위치에 함께 업로드하세요. 홈 하단 1.17.0을 확인하세요.
1.16의 GPT-6.2 Sol 원고 및 GPT Image 2.6 Flare 이미지 모델 업데이트가 포함되어 있습니다. 이미 1.16을 배포한 경우 경주와 선수 등록 변경은 GitHub Pages에 있습니다.

선수 두 명 준비
부모님 → 경주 선수 만들기 → 아이와 도감 친구 선택 → 원본 사진 받기 → 요청문 복사.
이미지 생성 대화에 원본 사진 한 장을 첨부하고 요청문을 붙여 넣습니다. 아이마다 별도로 진행하세요. 투명 배경 PNG 권장, 자홍색 배경도 가능합니다. 4열 × 3행, 총 열두 동작이 한 장에 들어갑니다. 옆으로 달리는 행은 오른쪽을 향하고, 둘째 행은 정면, 셋째 행은 뒷모습입니다.
동일한 아이·캐릭터가 선택된 상태에서 생성한 그림을 열고 세 방향 미리보기를 확인한 뒤 등록합니다. 피사체가 잘리거나 다음 칸의 일부가 보인다면 등록 전 원본 시트의 칸 간격을 바로잡아 주세요.
동물 경주에서 평소처럼 캐릭터를 고르면 자동으로 등록된 동작이 나옵니다. 다른 친구는 기존 사진 방식입니다. 가게의 신발과 지갑은 그대로이며 등록한 그림은 이 기기의 도감 전체 백업에 포함됩니다. 교체·해제도 부모님 화면에서 할 수 있습니다. 등록은 게임 API를 호출하지 않습니다.
경주: 초당 한 번이면 기존과 같이 약 25초(새싹 운동화), 빠른 입력 보너스 최대 +13%. 신발의 속력 차이를 없애지는 않습니다.
캐릭터연구소 1.16.0 · 아이가 이길 수 있는 리듬 경주와 새 그림책 모델

설치
1. 평소 쓰는 태블릿에서 부모님 → 도감 전체 백업. 사이트 데이터를 지우지 마세요.
2. 기존 Cloudflare Worker의 Edit code에 worker/cloudflare-worker.js 전체를 넣고 Deploy. 붙여넣기가 어렵다면 편집창을 비운 뒤 worker/paste-parts 안의 텍스트를 01부터 번호순으로 이어 붙여 한 번만 Deploy 하세요. 기존 키·DB·한도는 그대로입니다.
3. GitHub Pages의 기존 index.html 위치에 github-pages 폴더 안의 내용(assets, forest-cup 포함)을 올려 한 번에 커밋하세요.
4. 게임을 새로고침하고 홈 하단 v1.16.0 확인. 부모님 → 그림책과 질문 → 이야기 모델이 GPT-6.2 Sol로 보이면 됩니다. 기존 도감은 다시 생성하지 않습니다. 1.15에서 서버에 저장한 하루 한도는 그대로이며, 그 전 버전에서 바로 넘어왔다면 원하는 하루 한도를 서버에 한 번 저장하세요.

경주
- 새싹 운동화(속력 10), 치타(10), 초당 1회로 약 25초. 카운트다운 제외. 누르는 간격이 조금 흔들려도 속도를 유지하고, 더 오래 쉬면 서서히 감속합니다.
- 맨발(4) 대 산토끼(5)는 약 0.8초에 한 번씩 누르면 이길 수 있습니다. 신발·상대 속력은 계속 반영하며 무한 연타 보너스는 없습니다.
- 스페이스, 엔터, 터치 발판 모두 같은 규칙입니다. 길게 누르면 자동으로 달리지 않습니다.

생성 모델
- 합체·먹이 그림과 모든 새 그림책 삽화는 gpt-image-2.6-flare, 1024×1024, quality low, complexity low, 1장씩입니다. 사진 두 장을 참고하는 합체 방식은 같습니다. 입력 사진에 따라서도 요금이 달라집니다.
- 새 그림책 원고·질문은 gpt-6.2-sol이 기본입니다. 예전 버전 설정/백업은 새 기본값을 적용하고, 업데이트 후 부모님이 기존 모델을 직접 선택해 저장하면 그 선택을 유지합니다. 완성된 책은 그대로, 중단한 책은 남은 삽화만 새 모델로 생성합니다.
- 모델 이용 권한 오류는 OpenAI 프로젝트 설정을 확인하세요. 오류가 났다고 다른 모델로 자동 유료 재시도하지 않습니다.

경주용 캐릭터 시안
RUNNER-ART-PILOT.txt에 도감 사진을 게임용 선수로 디자인해 보는 요청문 두 개를 넣었습니다. 다음 그래픽 작업을 위한 선택 실험이며, 현재 게임은 별도 이미지 생성 없이 기존 도감 캐릭터로 작동합니다.

기존 한도 및 이용 안내
- 오늘 요청 횟수 초기화: 오늘 합체·먹이 그림만.
- 오늘 그림책 횟수 초기화 · 원고와 삽화: 오늘의 원고와 삽화를 함께. 이미 저장한 원고·페이지는 도감에서 이어 만들 수 있습니다.
- 이번 달 전체 요청 횟수 초기화: 이번 달 합체·먹이 그림, 원고, 삽화 모두. 오늘 횟수는 그대로입니다. 일·월 모두 막혔다면 둘 다 해당 기간을 초기화하세요.
- 초기화는 게임 카운터만 다시 열고 이미 발생한 비용, 기존 작품과 요청 ID는 보존합니다. 생성 중에는 완료 후 초기화하세요. 표시는 한국 시간 기준입니다.
- 한도 오류는 원고/삽화/캐릭터 사진, 일/월을 나누어 표시합니다. 선불 크레딧 소진, OpenAI의 지출 제한, 요청 속도 제한은 별도입니다.
