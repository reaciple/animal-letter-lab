# v1.8.0 업데이트 — 내 친구와 보석 달리기

기존 캐릭터연구소에 별도 메뉴인 **보석 달리기**를 추가했습니다. 새 캐릭터를 만들지 않아도 아이별 도감에서 이미 만들어 둔 합체캐릭터를 골라 바로 놀 수 있습니다.

## 플레이 방법

1. 첫 화면의 **내 친구와 보석 달리기**, 또는 위 메뉴의 **보석 달리기**를 누릅니다.
2. 아이의 도감을 선택하고 주인공 사진을 고릅니다. 첫 그림과 먹이주기 후 그림 모두 사용할 수 있습니다. 아직 도감이 없으면 **연습 친구로 체험하기**도 가능합니다.
3. **달리기 시작**을 누르면 자동으로 달립니다. 화면 또는 **점프** 버튼을 손가락·S펜으로 누르세요. 컴퓨터에서는 Space / ↑ 키도 됩니다.
4. 공중에서 한 번 더 누르면 2단 점프를 합니다. 보석 43개와 나무토막이 있는 약 50초 숲길을 달립니다. 기기 성능에 따라 시간이 조금 길어질 수 있습니다.
5. 장애물에 닿아도 실패하지 않고 계속 달립니다. 끝나면 모은 보석 수를 확인하고 다시 할 수 있습니다.

**잠깐 쉬기**로 일시정지할 수 있고, 다른 앱으로 이동하면 자동으로 쉬는 화면이 됩니다. 캐릭터 고르기로 나가거나 새로고침하면 이번 달리기는 처음부터 시작합니다. 달리기 기록은 저장하지 않습니다. 기존 도감·사진·이야기에는 영향을 주지 않습니다.

이번 버전은 사진을 담은 작은 캐릭터가 움직이는 테스트용입니다. 사진에서 배경을 제거하거나 전신 달리기 동작을 AI로 새로 만드는 기능은 아닙니다. 따라서 추가 API 호출·비용이 없습니다. 향후 배경을 제거한 캐릭터, 달리기 애니메이션, 여러 코스, 글자·숫자 수집으로 확장할 수 있습니다.

## 적용 방법 — v1.7.1을 적용했다면 GitHub만 업데이트

1. 게임의 부모님 설정에서 도감 백업을 내려받아 보관합니다. 예방용 백업이며 복원하거나 초기화할 필요는 없습니다.
2. `animal-letter-lab-update-v1.8.0.zip`을 내려받고 압축을 풉니다.
3. GitHub의 **reaciple / animal-letter-lab** 저장소를 엽니다. 현재 사이트를 배포하는 폴더(보통 저장소 맨 위)로 이동합니다.
4. **Add file → Upload files**를 누릅니다.
5. 압축 안의 **github-pages 폴더를 열고 그 안의 파일과 폴더 전체**를 업로드합니다. `github-pages` 폴더 자체를 한 겹 더 넣지 마세요. `index.html`과 `assets` 폴더를 반드시 함께 업데이트해야 합니다.
6. 아래의 **Commit changes**를 눌러 저장합니다. GitHub의 **Actions**에서 Pages 배포가 완료될 때까지 기다립니다.
7. 원래 게임 주소를 새로고침합니다. 첫 화면 아래 **v1.8.0**과 **보석 달리기** 메뉴가 보이면 적용된 것입니다. 예전 화면이면 컴퓨터에서는 Ctrl+Shift+R, 태블릿에서는 탭을 닫고 같은 주소를 다시 엽니다. 브라우저 사이트 데이터는 지우지 마세요.

`.nojekyll`은 이미 있으면 그대로 두세요. 업로드 목록에서 보이지 않아도 이번 변경을 위해 새로 만들 필요는 없습니다. `source`는 다음 수정을 위한 원본이므로 GitHub 사이트 루트에 업로드하지 않아도 됩니다.

**Cloudflare Worker, API 키, 변수, D1 설정은 이번 기능 때문에 바꿀 필요가 없습니다.** v1.7.1의 먹이 생략·그림책 개선까지 적용되어 있다는 기준입니다. 아직 이전 기능의 Worker를 적용하지 않았다면 이 압축의 `worker/cloudflare-worker.js`에는 기존 최신 기능도 포함되어 있으므로 그때만 Worker 코드를 함께 교체·배포하세요. 기존 변수·Secret·D1 연결은 유지합니다.

## 확인한 범위

기존 기능과 달리기 로직을 포함한 자동 테스트 58개, TypeScript 검사, 배포용 빌드를 통과했습니다. 브라우저에서 메뉴, 연습 캐릭터, 시작, 점프, 일시정지·재개를 확인했습니다. 실제 Galaxy Tab S7 / S펜에서는 직접 테스트하지 못했으므로 먼저 짧게 플레이해 주세요. 이번 검증으로 유료 API는 호출하지 않았습니다.
